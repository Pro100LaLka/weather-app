HTML + CSS + JS. Weather App. The project I'm most proud of so far. My skills shown in this project:

- JavaScript architecture split into ES modules (state → render, single source of truth; separate data, render and helper modules)
- Async/await with multiple chained APIs and error handling (IP geolocation → forecast, city geocoding)
- City search with autocomplete and debounced input
- Explicit UI states (loading, empty, error with retry), switched in CSS via a data-status attribute
- Metric/imperial unit switching (whole system or per unit)
- Automatic user location detection on load
- localStorage management (units, recent searches — deduplicated, capped)
- Event delegation
- Accessibility (semantic HTML, accessible combobox with ARIA roles, reduced motion)
- Responsive design
- CSS custom properties
- CSS-first interactivity (:has, :checked, details/summary — no JS where CSS suffices)
- BEM naming
